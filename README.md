# Домашнее задание: простая LLM-модель для предсказания следующего слова

Простая языковая модель на Python 3 (биграммная модель по частоте встречающихся слов), которая обучается на подготовленном датасете и предсказывает слово, следующее за заданным.

## Как работает

- Метод `train(data)` разбивает каждое предложение на слова и считает частоты биграмм: для каждой пары соседних слов `(текущее слово, следующее слово)` увеличивается счётчик в `self.ngram_counts`.
- Метод `predict_next_word(start_word)` возвращает самое частотное слово, которое встречается после заданного. Если слово не найдено в обучающей выборке или для него нет данных — возвращается соответствующее сообщение.

## Запуск

```bash
python3 test_llm.py
```

## Пример вывода

```
Входное слово: 'кот'
Предсказанное следующее слово: 'спит'
```

После слова «кот» в датасете слово «спит» встречается 3 раза — чаще всех остальных («ест», «играет», «гуляет» — по 2 раза, «смотрит» — 1 раз), поэтому модель предсказывает именно его.
